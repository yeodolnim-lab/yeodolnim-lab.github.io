깨워연두 개인정보처리방침

시행일: 2026-10-07

개발자: Team DM Studio

지원 이메일: [yeodolnim@gmail.com]

1. 기기 내 저장 정보

알람 설정, History, 캐릭터 XP/레벨/연속 성공, 광고 빈도 상태, 사용자가 선택한 음악의 SAF URI와 읽기 권한을 기기 내부에 저장할 수 있습니다. 개발자가 운영하는 자체 서버로 알람/History/XP/음악 파일을 업로드하지 않습니다.

2. 광고

앱은 Google Mobile Ads SDK(AdMob) 및 Google User Messaging Platform(UMP)을 사용합니다. Google SDK는 광고 제공·측정·분석·부정행위 방지를 위해 IP 주소, 대략적 위치, 앱/광고 상호작용, 진단 정보, Android 광고 ID, App Set ID 등의 정보를 처리할 수 있습니다.

3. 권한

알림, 정확한 알람, 전체 화면 알람, 진동, 부팅 후 알람 복원, 포그라운드 서비스 관련 권한을 사용할 수 있습니다. 사용자 음악 선택에는 Android SAF를 사용합니다. 광고 목적으로 연락처, 카메라, 마이크, 정밀 위치 권한을 요청하지 않습니다.

4. 보관 및 삭제

로컬 데이터는 사용자가 삭제하거나 앱 데이터를 초기화하거나 앱을 삭제할 때까지 보관될 수 있습니다. 계정 생성 기능은 없어 별도의 계정 삭제 절차는 없습니다. 광고 SDK 데이터의 보관·삭제는 Google 정책에 따릅니다.
